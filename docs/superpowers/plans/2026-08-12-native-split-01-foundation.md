# 原生 split 布局 — 计划一：地基（config 与实测）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 herdr 停止绘制 pane 字符边框与字符滚动条、在 pane 之间留出恰好一格，并实测确认 `pane.layout` 的 rect 与 grid 内容的对应关系。

**Architecture:** 纯配置改动，不动任何渲染或协议代码。`RuntimePaths.configContents` 增加三个 pane 键与三个 modal 键；另写一个空的 product-announcement store 压掉唯一没有 config 开关的启动弹窗。之后用 `herdr` CLI 对 herda 自己的隔离 server 做四项实测，把结论写回 spec。

**Tech Stack:** Swift 6 / XCTest / `herdr` CLI（0.8.0）/ `Scripts/test.sh` / `Scripts/run.sh`

依据文档：`docs/superpowers/specs/2026-08-12-native-split-layout-design.md`（硬约束一、二、五、六与「待实测项」四条）。

**完成后的可见变化：** split 之后 pane 之间不再有 ratatui 画的 `│` `─`，而是一格空白。原生卡片还没有（计划三才做），所以此时看到的是「pane 之间有一条空白缝」。这是中间态，但已经可用，且用户最初抱怨的字符分割线在这一步就消失了。

    /// 写一个 `latest` 为空的公告 store。见 `announcementStore` 的注释。
    public func writeEmptyAnnouncementStore() throws {
        try FileManager.default.createDirectory(
            at: announcementStore.deletingLastPathComponent(),
            withIntermediateDirectories: true
        )
        try Data(#"{"latest":null,"seen":[]}"#.utf8).write(to: announcementStore)

        try writeEmptyAnnouncementStore()
    }
